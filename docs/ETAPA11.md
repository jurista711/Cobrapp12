# Etapa 11 — Contatos e WhatsApp

- Ações de ligação e WhatsApp no cadastro de clientes.
- Cobranças exibem atalho para WhatsApp com mensagem pré-preenchida contendo cliente, vencimento e saldo.
- O envio continua sendo feito pelo aplicativo externo do usuário; o CobrApp apenas abre o WhatsApp com a mensagem preparada.
- Telefones são normalizados para uso no formato internacional do Brasil (55) quando necessário.
- Não foi criada dependência de Firebase para este fluxo.
